# Atrium releases

Binaries of `atriumd` for Linux servers, published by the Atrium release workflow.

- `latest/atriumd-x86_64-unknown-linux-gnu`
- `latest/atriumd-aarch64-unknown-linux-gnu`
- `latest/VERSION`
- `versions/<tag>/…`

The installer downloads from `https://raw.githubusercontent.com/R-Juhl/atrium-releases/main/latest`.
